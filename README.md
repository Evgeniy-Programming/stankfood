# Stank FOOD

Обновленный учебный Flask-проект под ТЗ сервиса онлайн-заказа питания.

## Что сделано
- оставлены только 2 столовые
- адаптивный интерфейс без "слипания" на мобильных экранах
- рабочие регистрация и авторизация
- фильтрация меню по категориям
- корзина с изменением количества и удалением
- оформление заказа со слотом выдачи и правилом предзаказа 30 минут
- demo-оплата
- уникальный номер заказа и QR payload
- личный кабинет с историей заказов, любимыми блюдами и уведомлениями
- повтор заказа
- панель персонала для смены статусов заказа
- аналитика по выручке, статусам, популярным блюдам, дням недели и времени суток
- удалена страница поддержки
- все ссылки интерфейса ведут на существующие страницы

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 main.py
```

Открыть:
- http://127.0.0.1:5000

## Тестовые аккаунты
- admin: `+70000000001` / `admin123`
- staff: `+70000000002` / `staff123`
- customer: `+70000000003` / `student123`

## Важно
При каждом запуске `main.py` база пересоздается для чистого демо-состояния.
